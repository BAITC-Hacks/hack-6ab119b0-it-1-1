# 1. Beeline Adaptive Campaign Agent

## 2. Description

Offline tariff campaign planning for HackAlem AI Track 04. The agent uses history to prioritize experiments, learns from noisy pilots, and allocates campaigns under the organizer's budget and contact limits.

## 3. Implemented features

- Standalone public `Agent.act(env)` entry point in `agent.py`.
- Historical priors adjusted by current-audience pilot evidence and uncertainty.
- Broad push-pilot exploration followed by adaptive confirmation or alternative tests.
- Audience and channel selection with contact ordering, budget, campaign-slot, and final-audience overlap accounting.
- Reproducible `submission.csv` generated by the unchanged organizer script with seed 42.

## 4. Approach

Rank current-tariff and ARPU cells using historical relative ARPU changes and transition shares. Start with up to sixteen 200-contact push pilots, then use remaining pilots to investigate uncertain or unexpectedly promising decisions. Push has zero communication cost but still consumes contacts and can cause negative revenue effects.

Combine noisy observations with a historical prior. Weaken the prior when pilots contradict it, calibrate its overall strength from current observations, and stop further exploration when pilots show widespread harm. Historical transition share is a ranking signal, not a measured conversion probability for the current audience.

Build candidate campaigns from tested cells, supported usage filters, and unions of compatible cells. Compare channels using conservative conversion scaling. Six deterministic greedy allocation variants trade contact reach against communication cost, respecting ID-ordered truncation and avoiding overlap between final campaigns. If no positive allocation is supported, use a scoped tested-audience fallback when feasible; profit is not guaranteed.

The policy accesses only public environment fields, `run_pilot`, and participant historical data. It does not import scoring internals or inspect hidden effects.

## 9. Data, integrations, and attribution

Inputs are the organizer's synthetic participant data. Monetary values are conventional units, not tenge. Policy execution needs no network connection or API key after dependency installation.

The policy is adopted unchanged from Adil Rakhaliyev's [source commit `41f934a`](https://github.com/BAITC-Hacks/hack-6ab119b0-it-1-1/commit/41f934ad122fb180e08cf3dc7ae6ffc9c25a3fb4). Balgow integrated the minimal submission package and verified the comparison and replay. Codex assisted integration, review, and testing.

This package does not call the OpenAI API. The development application's separate post-run OpenAI analyst is outside these four files. The event-wide OpenAI API requirement remains a separate delivery concern; this offline package alone does not demonstrate that integration.

## 10. Limitations

Mock results are not hidden-judge results or real-world revenue. Historical priors can fail when business effects change. In an authored reversed-history stress fixture, the adopted policy lost money on all ten tested seeds; that fixture is a diagnostic, not a prediction of judging effects. Initial pilots can cause harm that later stopping cannot undo.

Uncertainty margins, channel scaling, and greedy allocation are heuristics. Pilot/final overlap can reduce realized gain relative to policy estimates. If no usable pilot evidence or remaining contacts exist, the fallback can return an empty plan, which violates the nonempty final-plan requirement; this did not occur in the 200-seed mock suite. Malformed or infeasible environments are not claimed to be fully supported.
